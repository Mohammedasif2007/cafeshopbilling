# Asif Cafe Billing System

## 📌 Project Overview

**Asif Cafe Billing System** is a web-based cafe billing application developed using **HTML, CSS, and JavaScript**. The project is designed to make cafe billing, product management, and sales tracking simple, fast, and user-friendly.

The system provides separate access for **Owner and Employee**, allowing different users to perform their respective tasks. It also includes automatic bill calculation, printable bills, sales tracking, and a responsive interface.

## 🚀 Features

* Owner and Employee Login
* Product selection and billing
* Add, update, and remove products from the bill
* Automatic calculation of subtotal and total amount
* Generate and print customer bills
* Daily sales tracking
* Monthly sales reports
* Owner dashboard
* Dark/Light mode
* Responsive design for desktop and mobile devices
* Simple and user-friendly interface

## 🛠️ Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling, layout, responsiveness, and UI design
* **JavaScript** – Billing calculations, interactions, login logic, and dynamic functionality

## 💡 How It Works

1. The user opens the application.
2. The user logs in as an **Owner** or **Employee**.
3. Products are selected from the available menu.
4. Selected products are added to the billing section.
5. JavaScript automatically calculates the total amount.
6. The bill can be generated and printed.
7. Sales information can be viewed through the dashboard and reports.

## 🎯 Project Objective

The main objective of this project is to create a simple digital billing solution for a cafe that reduces manual calculation, improves billing accuracy, and makes daily sales management easier.
